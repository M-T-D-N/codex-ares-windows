# Privacy and public evidence

The adapter uses the user's existing Codex authentication loader; it never distributes or clones home/config/auth/DB. Luna-only operation does not read a Jev key. Selecting Jev sends bounded current decision input to TypeSafe with potential usage charges. Set the secret in a private process environment or a private file outside this repository; CLI arguments and committed `.env` values are inappropriate.

Default sidecar events are an allowlist of structural metadata, usage and judgment action/effort. Full prompts, result bodies, environment maps, command identity and judgment explanations are omitted. `ARES_DIAGNOSTIC_LOGS=1` explicitly adds bounded probability/answer/coverage/statistic diagnostics; those diagnostics may contain local metadata and remain private. Local receipt/status files necessarily include IDs and process paths for ownership checks. Do not publish runtime directories, manifests or stdout/stderr without a new review.

Historical research files are excluded from this source repository. The optional pilot-results document contains allowlisted statistics and tables, not prompts, private files, transcripts, mail/search details, authentication material or process command lines. Original traces and the private ID map remain private. Unit tests use synthetic inputs only; runtime receipts/status/logs are ignored local data, never public fixtures.

The public manifest hashes the exact selected source files. It is a consistency check, not an OpenAI/TypeSafe signature. Private-input hashes do not substitute for semantic reproducibility. The preview has no imported private Git history and no remote. A final publication allowlist plus content scan covers patch context, fixtures, manifests, licenses and docs, not just executable source. Upstream generic synthetic filesystem paths inside code/tests are distinguishable from personal machine paths and are documented in the local review.
